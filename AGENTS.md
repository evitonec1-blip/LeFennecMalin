# Project Instructions & Automation Rules

## Git Repository Synchronization Rules
1. **Always push changes to the remote repository** when completing user tasks.
2. **Exclude Image Assets from Commits**: Never stage or commit any Fenny mascot images or site images (`public/fennec-avatar.jpg`, `public/fennec-logo.jpg`, mascot/avatar `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.ico` files) to prevent image corruption/blank glitches.
3. Repository Remote: `origin` (branch: `main`).
